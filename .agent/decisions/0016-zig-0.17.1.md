# ADR 0016: Upgrade the Project Toolchain to Zig 0.17.1

- Status: Accepted
- Date: 2026-11-07
- Supersedes: ADR 0001 for the target toolchain, after migration completion

## Context

At the time of this decision, the project targeted Zig 0.13.0. The owner approved a deliberate migration to Zig 0.17.1 as a dedicated compatibility task. This release includes breaking changes across the build system, process and standard I/O, filesystem APIs, and language/standard-library interfaces. A one-line version bump is not sufficient.

## Decision

Upgrade the complete codebase and CI toolchain to Zig 0.17.1 through the phased migration recorded in [TOOLCHAIN-001](../tasks/TOOLCHAIN-001-zig-0.17.1-migration.md).

The migration must preserve gameplay behavior, command syntax, Save V3 serialization, V2/V1/legacy read compatibility, atomic save replacement, bounded REPL input behavior, and writer-failure transactional guarantees.

The implementation will be performed directly on `main` in focused commits. No feature branch is required.

During the migration, the default CI pin remained Zig 0.13.0 until the full application, tests, and final CI matrix were verified. That staged restriction has now been satisfied; see Implementation status below.

## Consequences

- TOOLCHAIN-001 is the authoritative migration scope, phase plan, audit, acceptance criteria, and agent handoff.
- Active agent instructions and user/developer docs must be updated consistently when the migration is complete.
- The new CI toolchain pin must not be switched prematurely if doing so would leave the default branch knowingly broken.
- Save format and gameplay changes are explicitly out of scope.


## Implementation status

Implemented on `main`. The project and primary CI are pinned to Zig 0.17.1. The build uses explicit root modules and `addPassthruArgs`; the process entry point uses `std.process.Init`/`std.Io`; persistence uses `std.Io.Dir` and preserves Save V3 bytes plus V2/V1/legacy reads. The complete aggregate test suite includes terminal I/O, save I/O, and facade API tests. Final primary CI run `42309239657` on reviewed commit `574f6bb13f018952847d13bae1ee39df48711144` passed Debug, ReleaseSafe, and ReleaseFast, including exact version confirmation, formatting, build, terminal entry-point smoke invocation, the full aggregate test suite, and agent-doc validation. The final self-review recorded no blockers and one non-blocking local terminal-control-output hardening suggestion.
