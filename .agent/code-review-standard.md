# Code Review Standard — Canonical Location

The mandatory and exhaustive Code Review Standard is maintained in **[review-checklist.md](review-checklist.md)**.

This file is retained as a compatibility pointer for agents or task handoffs that refer to `.agent/code-review-standard.md`. It is not a separate checklist and adds no independent rules. Read `.agent/review-checklist.md` in full and follow every applicable criterion, pass order, severity, evidence requirement, and report section defined there.

Do not use an older copy of this document or combine it with a conflicting checklist. If a criterion needs to change, update `.agent/review-checklist.md` as the single source of truth and keep this pointer intact.
